Rust Send 和 Sync

pmnmq 发布于 2023-08-24 收录于 Rust
  • Send 和 Sync 这两个 Trait 在跨线程的时候需要关注
    • Send: A type is Send if it is safe to send it to another thread.
    • Sync: A type is Sync if it is safe to share between threads (T is Sync if and only if &T is Send)

Send 和 Sync 是 Rust 并发机制的基础。因此，Rust 赋予它们许多的特性，以保证它们能正确工作。首当其冲的，它们都是非安全 trait。这表明它们的实现也是非安全的，而其他的非安全代码则可以假设这些实现是正确的。由于它们是标志 trait（它们没有任何关联的方法），“正确地实现” 仅仅意味着实现满足它所需要的内部特征。不正确地实现 Send 和 Sync 会导致未定义行为。
