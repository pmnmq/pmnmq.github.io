Solana Playground

solana Playground 地址 https://beta.solpg.io/

打开之后左下角显示的状态是未连接，因为没有连接 Solana 网络，这需要有一个钱包地址，因为是测试开发，可以使用测试网络

点击左下角可以马上分配一个测试网络的钱包地址，点击 continue 即可

完成之后左下角会显示 0 SOL，如果需要 SOL 就需要使用水龙头进行空投

使用水龙头空投

https://faucet.solana.com/

将 Solana playground 中的钱包地址填入

选择好金额后确认空投地址，这样钱包地址就有测试的 token 了

下方现在已经显示有 5 个 SOL

安装 cli

安装 rust

Solana 开发需要使用 rust

https://www.rust-lang.org/tools/install

安装 Solana cli

sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"

下载完成之后会提示需要添加到环境变量，添加到环境变量之后重新加载一次，然后就可以使用了

solana --version

安装Anchor cli

Anchor 是一个用于开发 Solana 程序的框架。Anchor 框架利用 Rust 宏简化编写 Solana 程序的过程。

官方推荐安装 Anchor 包管理器 AVM (Anchor version manager)

使用 rust 包管理器 Cargo 安装

cargo install --git https://github.com/coral-xyz/anchor avm --force

验证是否安装成功

avm --version

使用 avm 安装最新的 Anchor cli

avm install latest

验证是否安装成功

anchor --version

安装 nodejs

这里不再赘述如何安装 nodejs，安装 nodejs 是因为 anchor 默认的测试项目文件使用的是 typescript 需要使用 yarn 进行安装

Solana 配置

solana config get

RPC URL 和 Websocket URL 指定了 CLI 发起请求的 Solana 集群。

可以使用以下命令更新 Solana CLI 集群：

solana config set --url mainnet-beta
solana config set --url devnet
solana config set --url localhost
solana config set --url testnet

也可以使用简短命令

solana config set -um    # For mainnet-beta
solana config set -ud    # For devnet
solana config set -ul    # For localhost
solana config set -ut    # For testnet

创建钱包

solana-keygen new

如果已经有钱包了，需要覆盖需要加上 --force

solana-keygen new --force

查看钱包公钥地址

solana address

空投 SOL 到钱包

首先需要将钱包环境设置为开发环境

solana config set -ud

然后发送空投请求

solana airdrop 2

如果空投失败可以使用水龙头网站进行空投

查看余额

solana balance
