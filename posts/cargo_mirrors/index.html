  • cargo 设置国内源

cargo 1.68 版本开始支持稀疏索引：不再需要完整克隆 crates.io-index 仓库，可以加快获取包的速度。如果 cargo 版本大于等于 1.68，可以直接使用而不需要开启 nightly。

cargo 设置国内源

config file path: $HOME/.cargo/config

[source.crates-io]

replace-with = 'tuna'

[source.tuna]
registry = "sparse+https://mirrors.tuna.tsinghua.edu.cn/crates.io-index/"

如果感觉清华大学开源软件镜像站的镜像比较慢的话可以使用字节的镜像 http://rsproxy.cn/
